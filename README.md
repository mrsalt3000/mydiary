# Local Diary

Локальный (local-first) однопользовательский личный дневник для WSL 2: текстовые и голосовые сообщения, ручная транскрипция, еженедельные TXT-выгрузки и три производных слоя (нормализация, саммари, осторожная wellbeing-рефлексия) с независимой настройкой локальных или внешних моделей для каждой задачи.

## Статус репозитория

**Архитектура и документация только; реализация приложения не начиналась.**

Репозиторий подготовлен к строго последовательному исполнению бэклога: созданы структура каталогов, операционный контракт, архитектурный бриф, ADR, описания навыков и политики данных. Исполняемого кода, зависимостей, БД, конфигураций и пользовательских данных нет.

## Структура каталогов

```text
.
├── tasklist.md          # бэклог задач (источник исполнения)
├── AGENTS.md            # контракт для агентов
├── README.md
├── docs/                # архитектура, ADR, политики
├── skills/              # SKILL.md по областям
├── prompts/             # версионируемые промпты (normalize/summarize/wellbeing)
├── configs/             # политика конфигурации (примеры)
├── src/                 # будущий пакет src/diary/ (пусто)
├── tests/               # unit/ integration/ fixtures/ (пусто)
├── data/                # приватные данные: db/ audio/ exports/ temp/ backups/
├── docker/              # будущие Dockerfile'ы (пусто)
└── scripts/             # будущие скрипты (пусто)
```

## Ближайшее действие

Исполнение `tasklist.md` начинается с Task 01. Обязательный следующий шаг: провести анализ Task 01, предложить отдельный план (файлы, тесты, команды валидации) и дождаться явного подтверждения — согласно [`docs/execution-protocol.md`](docs/execution-protocol.md) и [`AGENTS.md`](AGENTS.md).
