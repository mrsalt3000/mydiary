{# Delete action of one diary message (task T15, ADR-011). Included by ``_message.html`` for text and voice messages alike, so the control — and its accessible name — is the same everywhere (including the htmx-loaded "older messages" fragment). Deletion is irreversible: the message text and, for a voice message, the stored audio file are erased. It therefore needs an explicit second step — a real button in a panel, never a purely visual hint. The panel starts hidden and is revealed by app.js; the request goes to the existing ``DELETE /api/v1/messages/{id}`` and never carries any diary content. ``aria-label`` names the message (its timestamp) so the repeated "Удалить" is unambiguous in a screen-reader button list. #}
