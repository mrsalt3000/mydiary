# data/ — локальные и приватные данные

**Всё реальное содержимое этого каталога — личные данные пользователя. Оно локально и не должно попадать в систему контроля версий (Git) ни при каких условиях.**

В этом каталоге не хранятся и не создаются: секреты, примеры данных для тестов, служебные файлы репозитория. Здесь живут только данные приложения, создаваемые в рантайме задачами Task 04 и далее.

## Политика

- Реальные БД, аудио, выгрузки, артефакты и бэкапы **не коммитятся**.
- В Git отслеживаются только этот README и `.gitkeep`-заполнители пустых подкаталогов.
- Физический `.gitignore`, исключающий содержимое `data/`, вводится в Task 01 (по `../tasklist.md`); до этого репозиторий Git не инициализирован и данные не создаются.
- Резервирование данных — ответственность пользователя; процедура бэкапа/recovery реализуется в Task 18.
- Автоматическое удаление исходных аудио и артефактов не выполняется; очистке подлежит только `data/temp/` по политике Task 18.

## Назначение подкаталогов

| Каталог | Содержимое |
|---|---|
| `db/` | SQLite-файл приложения (источник истины метаданных; ADR-001) |
| `audio/` | Аудиосообщения: `YYYY/MM/` с серверными UUID-именами (ADR-002) |
| `exports/01_original/` | Оригинальные недельные выгрузки (слой 1, неизменяемы) |
| `exports/02_normalized/` | Нормализованные артефакты (слой 2, версии `vM`) |
| `exports/03_summaries/` | Саммари (слой 3, версии `vM`) |
| `exports/04_wellbeing/` | Wellbeing-рефлексия (слой 4, версии `vM`) |
| `temp/` | Временные файлы при записи/обработке (очистка по политике Task 18) |
| `backups/` | Архивы бэкапов (Task 18) |
