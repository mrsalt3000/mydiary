# Навыки проекта (skills)

## Назначение

Каталог `skills/` содержит исполняемые руководства для будущих агентов по каждой области работ. Это **не** общие туториалы: каждый SKILL.md описывает, как именно выполняется работа в этом репозитории, с его правилами, модулями и проверками.

## Прецедент и порядок применения

- Приоритет документов (из `../AGENTS.md`): инструкции пользователя → `../tasklist.md` → `../AGENTS.md` → ADR (`../docs/decisions/`) и skills → локальные конвенции кода.
- Skills уточняют, **как** исполнять задачу из `tasklist.md`, но не меняют её скоуп и не отменяют цикл «анализ → план → подтверждение → реализация → валидация → отчёт» (`../docs/execution-protocol.md`).
- При противоречии skill и ADR/tasklist приоритет у ADR/tasklist; конфликт выносится пользователю.

## Как пользоваться навыком

1. Определить область задачи по `tasklist.md`.
2. Прочитать соответствующий SKILL.md до анализа/плана.
3. Следовать его обязательным правилам и проверкам; команды валидации в skills — целевые (появятся после настройки инструментов в Task 01), до этого их наличие не означает, что инструменты установлены.
