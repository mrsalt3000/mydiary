# Skill: weekly-export

## Purpose

Правила недельных выгрузок: границы недель в часовом поясе, сквозная нумерация без пропусков, ревизии оригинала, имена артефактов, детерминированный рендер, атомарная запись. Источник — `../docs/architecture-brief.md` §7 и `../docs/data-lineage.md`.

## Scope and boundaries

- Входит: вычисление границ недели, выбор сообщений недели, рендер оригинального TXT (слой 1), именование/нумерация/ревизии, атомарная запись, записи `weekly_exports`, re-export.
- Вне границ: LLM-конвейеры слоёв 2–4 (llm-pipelines); производное именование `vM` вводится в Task 12 (фреймворк) и здесь учитывается как конвенция.

## Mandatory rules

- Неделя: понедельник 00:00:00 – воскресенье 23:59:59.999999 в `APP_TIMEZONE` (по умолчанию `Europe/Moscow`); дата в имени — дата воскресенья.
- Пустая неделя: файл и номер не создаются. Номера `NNNN` — только фактическим оригиналам, без пропусков; номер переиспользуется в производных именах.
- Ревизии: первый экспорт недели — `r1`; повторный — только явным re-export, `rN+1`; перезапись более раннего файла запрещена.
- Включение сообщений: текст — как введено; аудио — метаданные + raw STT при наличии; нетранскрибированные аудио помечаются `[не расшифровано]`.
- Формат файла — по шаблону задачи Task 10 (заголовок: неделя, дата воскресенья, номер, ревизия, created ISO-8601, timezone; тело с `[timestamp] TEXT|AUDIO`).
- Рендер финального файла — бэкендом из данных БД (не LLM); порядок детерминированный.
- Атомарная запись: временный файл → flush/fsync → rename; согласованность файла и записи БД (path, hash, week_end_date, seq, revision).
- Файлы оригинала неизменяемы (ADR-005); скачивание/UI — по задаче Task 10/16.

## Expected module locations

- `../src/diary/domain/exports/` — границы недель, нумерация, рендер, скачивание.
- `../src/diary/core/` — часовой пояс/время.
- Таблица `weekly_exports` — в `../src/diary/db/`; артефакты слоёв — `data/exports/01_original/…04_wellbeing/`.
- Тесты: unit (границы/нумерация) и integration (файл↔БД).

## Quality and security checks

- Тесты: границы вокруг воскресенья/понедельника и смены пояса; пустая неделя; пропуски неактивных недель; ревизии; отсутствие STT; детерминированный порядок; согласованность после успеха/сбоя.
- Проверка байт-в-байт неизменности ранее созданных оригиналов после re-export и после конвейеров.
