# ADR-006: Wellbeing-вывод — поддерживающая рефлексия, не диагноз; детерминированная эскалация

- Status: Accepted
- Date: 2026-09-09

## Context

Функция wellbeing-рефлексии (слой 4) работает с личными записями о самочувствии. LLM может формулировать утверждения, которые пользователь воспримет как медицинские/психологические выводы. Это зона повышенного риска: нужны строгие границы содержания и детерминированное поведение при признаках кризиса, не зависящее от свободной генерации.

## Decision

Wellbeing-рефлексия — это поддерживающий, фактически обоснованный текст, а не диагноз:

- Вход — только нормализованный текст (слой 2); запуск — только явное действие пользователя с подтверждением в UI; автозапуск запрещён.
- Вывод структурно разделяет наблюдаемые факты и осторожную интерпретацию; рекомендации — 1–3 низкорисковые, привязанные к фактам; указываются уверенность и ограничения.
- Запрещены: диагностические ярлыки, планы лечения, выдуманные симптомы, утверждения о причинности, неподтверждённые утверждения.
- Каждый отчёт содержит обязательную оговорку: это не медицинский/психологический диагноз и не замена профессиональной помощи.
- Вводится детерминированный слой правил с уровнями `normal` / `needs_support` / `urgent`. При `urgent` пользователь получает **фиксированный** эскалационный контент и действия, определённые кодом (не LLM); записывается безопасный минимум метаданных. Свободный LLM-текст не управляет кризисным сценарием.
- Настройка приложения может полностью отключить wellbeing-анализ.

## Consequences

Положительные:

- Снижение риска вреда от необоснованных выводов; предсказуемое поведение в чувствительных случаях; ясные границы ответственности продукта.

Отрицательные/требующие внимания:

- Ограниченная полезность (без диагностики) — это сознательное решение.
- Классификатор `urgent` обязан быть консервативным и проверяться тестами на синтетических данных (Task 15); ложные срабатывания допустимы, пропуски — нет.
- Требуется аккуратная формулировка оговорок и эскалационного контента на русском языке; содержание — не медицинская рекомендация.

## Alternatives considered

- Полный запрет wellbeing-функции: теряет заявленную ценность продукта; не выбран, но функция отключаема конфигурацией.
- Свободный LLM-ответ и на `urgent`: недетерминированно и рискованно; отклонено — только детерминированный сценарий.
- Диагностические утверждения с оговоркой «не является диагнозом»: противоречиво и рискованно; отклонено.
